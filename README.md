# Atlas Review downloads

Atlas Review source and current releases now live at [Loomtide/atlas-review](https://github.com/Loomtide/atlas-review).

Get the latest [Windows and Mac builds](https://github.com/Loomtide/atlas-review/releases/latest).

This repository retains the legacy updater feed so existing AtlasEngine installations can upgrade to the new signed builds. Old installers have been retired in favor of clean replacements. Application identifiers and data paths are preserved.
